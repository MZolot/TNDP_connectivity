# Разработка алгоритма генерации маршрутов общественного транспорта с учетом транспортной связанности
Автор: Золотарева Людмила Константиновна

## Данные
В работе используются синтетические и реальные геопространственные данные.
Синтетические данные представлены транспортной сетью Мандла и сохранены в формате CSV.
Представлены реальные данные по городу Усть-Илимск, включающие здания и кварталы городской территории, сформированные вручную. Дополнительные пространственные данные получены из открытого источника OpenStreetMap; код их загрузки и обработки представлен в репозитории. Все данные представлены в формате GeoJSON и предварительно обработаны для последующего использования в алгоритме.

## Метод

Предлагаемая методология включает в себя следующие основные этапы:
1)	Сбор и обработка данных о территории;
2)	Построение пула маршрутов;
3)	Генерация маршрутной сети с использованием генетического алгоритма. 

Обработка данных включает в себя упрощение графов и генерацию матрицы спроса на перемещения между кварталами на основе гравитационной модели.

В генетическом алгоритме особи представляют собой маршрутные сети, составленные из маршрутов, входящих в пул.
Алгоритм оптимизирует сети по следующим критериям:
- затраты пассажиров
- эксплуатационные издержки
- связность транспортной сети

Результатом работы является единственная сеть маршрутов общественного транспорта, которая получила наилучшее значение взвешенной функции за все время работы алгоритма.

## Структура репозитория
- `data/` - исходные данные
- `src/` - основная реализация алгоритма
  - `ga/` - алгоритм формирования пула и генетический алгоритм генерации маршрутов
  - `city_data_processing/` - загрузка и обработка данных, упрощение графов, генерация матрицы спроса и др.
  - `utils/` - инструменты визуализации и анализа результатов
- `experiments/` - скрипты для подбора параметров и анализа результатов
- `examples/` - примеры процесса использования алгоритма
